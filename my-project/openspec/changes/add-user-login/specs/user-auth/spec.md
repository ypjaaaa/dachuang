## Purpose

定义用户名密码登录能力：允许已注册用户通过用户名和密码换取访问令牌，作为身份认证与后续资源访问控制的基础。

## ADDED Requirements

### Requirement: 用户可通过用户名和密码登录

系统 SHALL 提供登录接口 `POST /auth/login`，接受用户名与密码，凭据校验通过后返回访问令牌。

#### Scenario: 登录成功

- **WHEN** 用户提交正确的用户名和密码
- **THEN** 系统返回 200 状态码，响应体包含一个访问令牌（`access_token`）及其过期时间

#### Scenario: 密码错误

- **WHEN** 用户提交正确的用户名但密码错误
- **THEN** 系统返回 401 状态码，并返回不含具体失败原因的通用错误信息

#### Scenario: 用户不存在

- **WHEN** 用户提交一个不存在的用户名
- **THEN** 系统返回 401 状态码，错误信息与「密码错误」场景一致，不泄露账户是否存在

### Requirement: 密码安全存储与校验

系统 SHALL 仅以不可逆哈希形式存储用户密码，校验时对提交的密码进行哈希后与存储值比对。

#### Scenario: 密码不存明文

- **WHEN** 系统保存或读取用户凭据
- **THEN** 存储层中不存在可读的明文密码，仅保留哈希值

### Requirement: 登录输入校验

系统 SHALL 对登录请求的输入进行校验，缺少必要字段或字段类型不符时返回校验错误。

#### Scenario: 缺少必填字段

- **WHEN** 用户提交的请求缺少 `username` 或 `password` 字段
- **THEN** 系统返回 422 状态码，并指出缺失的字段

#### Scenario: 字段类型不符

- **WHEN** `username` 或 `password` 字段不是字符串
- **THEN** 系统返回 422 状态码，并指出类型错误的字段
