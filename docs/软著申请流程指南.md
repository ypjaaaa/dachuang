## 二、申请步骤

### 第 1 步:确定著作权人(重要,先定)

- **以学校名义申请**(推荐):著作权人填学校名称(天津职业技术师范大学),需提供学校**营业执照/法人证书复印件 + 盖章**(联系校科研处/信息学院协助);
- **以团队/个人名义申请**:著作权人填成员姓名,需提供身份证复印件。
- ⚠️ 大创项目一般**以学校名义**申请更规范,成果归属与结题材料一致。**请先与指导教师确认**。

### 第 2 步:官网注册并填写申请表

1. 打开 https://www.ccopyright.com.cn → 注册账号(个人注册);
2. 进入「计算机软件著作权登记」→ 在线填报;
3. 关键填写项:

| 表单项 | 填写建议 |
|---|---|
| 软件全称 | 多模态会议内容转化与向量知识库软件 |
| 软件简称 | 会议知识库 |
| 版本号 | V1.0 |
| 开发完成日期 | 建议填 2026-12-01(与 PPT 计划第二阶段完成时间一致) |
| 首次发表日期 | 未发表则填"未发表"(不影响受理) |
| 开发方式 | 独立开发 |
| 著作权人 | 按第 1 步确认结果填写 |
| 权利取得方式 | 原始取得 |
| 软件用途和技术特点 | 参考说明书第二、五章 |

### 第 3 步:准备源程序文档(已生成,检查格式)

- 要求:每页 **50 行**(含空行/注释),页眉标注软件名称+版本号;
- 前后各 **30 页**(共 3000 行),**不足 60 页的全部提交**(本项目 15 页,全交);
- ⚠️ 提交前检查:
  - 去掉与软件无关的注释(如 TODO、调试语句);
  - 如担心代码量偏少影响审查观感,可在说明书中充分展开功能与技术细节(说明书已写得很完整);
  - 代码中不要出现他人版权信息。

### 第 4 步:准备说明书(已写好,需补截图)

1. 打开 `docs/软件说明书_V1.0.md`,把文中 3 处【此处插入截图】替换为**真实界面截图**:
   - 软件主界面(两个页签);
   - 导入会议页签(音频上传 + 转写结果);
   - 智能问答页签(一个完整问答 + 引用列表);
2. 截图方法:启动软件 → 浏览器打开 http://127.0.0.1:7860 → 操作对应功能 → 截图(推荐用浏览器开发者工具截图全页);
3. 导出为 PDF(建议用 Typora/VS Code Markdown 转 PDF,或打印为 PDF);
4. 说明书一般 **30 页左右为宜**,当前内容约 10 页,可适当补充截图与操作细节。

### 第 5 步:提交申请

1. 官网在线提交:上传申请表(签字盖章扫描件)、说明书 PDF、源代码 PDF、身份证明;
2. 缴费:登记费(目前 300 元/件,以官网为准);
3. 等待审查(一般 30-60 个工作日);
4. 审查通过后颁发《计算机软件著作权登记证书》。

## 四、常见问题

| 问题 | 解答 |
|---|---|
| 代码不到 3000 行可以吗? | 可以,不足 60 页的全部提交即可,如实反映即可 |
| 软著要交源代码完整版吗? | 只需前后各 30 页,但本项目代码少,全部提交 |
| 界面截图是必须的吗? | 说明书需图文并茂,截图是重要组成部分 |
| 以学校名义申请需要什么? | 学校法人证书/营业执照复印件 + 盖章,联系学院或科研处 |
| 软著会查重吗? | 主要形式审查;代码为原创即可 |
